# posr
# posr (Public Opinion and Survey Research) is an R package designed to streamline workflows in survey research and public opinion analysis. Core functions include mose(), which generates a margin of sampling error table with subgroup n sizes, weight summaries, and MOSE calculations; and stattest(), which runs weighted t-tests across subgroups to support significance testing in complex survey designs. The package also includes utilities for exporting analysis-ready outputs to Excel, handling mixed numeric and character columns that otherwise produce errors in Excel. posr was developed to reduce manual effort and standardize outputs across research teams, and is designed to work in conjunction with the wink package.
